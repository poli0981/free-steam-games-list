# Pre-releases

Notes for a beta, alpha or release candidate go here, one file per
pre-release, named for its version: `5.0.0-beta.1.md`. When the line goes
stable its release gets a file of its own under `v<major>/`; the beta files
stay, as the record of what changed during the run-up.

None has been published: every release so far, v1.0.0 to the latest in
[`CHANGELOG.md`](../../CHANGELOG.md), was a stable one.
